## 📌 今日深度推荐（2026-10-19）：Dashy

Dashy 是一款开源的个人导航仪表盘，说白了就是给你做一个超漂亮的浏览器起始页：把每天要打开的网站（邮箱、资讯站、银行、备考资料）按分类摆好，一眼找到、一点直达。最实用的三点：**状态小部件**（天气、日历、待办直接嵌在首页，不用逐个网站点开看）、**多页面分组**（工作、备考、生活各一张页签，互不干扰）、**颜值即战力**（几十种主题，打开浏览器心情都好）。一个具体技巧：建一个「晨间」页面，把 5 个资讯站、3 个银行入口、公考报名专题页全放进去，设为浏览器首页——早上打开浏览器，资讯和账单一次看完，比在收藏夹里翻快得多。
