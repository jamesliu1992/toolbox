## 📌 今日深度推荐（2026-10-12）：PowerToys

微软官方出的 Windows 效率工具集，免费。最实用的三个功能：**FancyZones**（窗口一键分区排布，写报告时左边资料右边文档）、**PowerRename**（批量重命名文件，整理下载文件夹神器）、**取色器**（Win+Shift+C 随时取屏幕颜色，做 PPT 配色用得上）。装完即用，不用学。
