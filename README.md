## 📌 今日深度推荐（2026-10-18）：Joplin

Joplin 是一款免费开源的笔记应用，界面和印象笔记很像，但没有会员套路、也没有广告。最实用的三点：**全平台同步**（手机、电脑记的笔记自动同步，通勤路上看的资料回家接着看）、**待办清单**（备考时把知识点整理成清单逐条勾掉，复习有成就感）、**数据自己掌控**（可同步到坚果云、OneDrive 等网盘，不怕厂商跑路）。一个具体技巧：用「待办事项」类型建一个「申论素材库」，每条素材单独一条，积累完打勾，复习时按标签筛选——比把所有东西堆在一个文档里好找得多。
